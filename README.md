# Manx Quality Sheds

Marketing website for **Manx Quality Sheds**, a family-run Isle of Man business
building bespoke sheds, summer houses, garden rooms, decking, fencing and full
garden transformations. Built with Next.js (App Router), TypeScript, Tailwind
CSS and Motion (Framer Motion).

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (Next.js will pick the
next free port, e.g. 3001, if 3000 is in use).

Build and run in production mode:

```bash
npm run build
npm run start
```

## Editing Content

Almost all business content lives in `src/lib/`, so you shouldn't need to
touch components to update copy:

- **Business info** (phone, email, address, social links): `src/lib/site-config.ts`
- **Services**: `src/lib/data/services.ts`
- **Projects / portfolio**: `src/lib/data/projects.ts` — the featured Western
  Red Cedar summerhouse is real project data; entries marked `isDemo: true`
  use clearly-labelled placeholder information and should be replaced with
  genuine project details and photography as they're supplied.
- **FAQs**: `src/lib/data/faqs.ts`
- **Testimonials**: `src/lib/data/testimonials.ts` — these are explicitly
  marked as placeholders in the UI. Replace with real, permissioned customer
  reviews when available.
- **Navigation**: `src/lib/data/nav.ts`
- **Process steps / "Why Choose Us"**: `src/lib/data/process.ts`,
  `src/lib/data/why-choose-us.ts`

## Branding

Real logo artwork lives in `public/branding/`, provided as PNGs in black,
tan/gold, white and (for one variant) charcoal, so the right contrast can be
used on any background:

- `logo-horizontal-*.png` &mdash; icon + wordmark, used in the header (black)
  and footer (black) navbar-style lockup.
- `logo-full-*.png` &mdash; icon + wordmark + "Bespoke and Imaginative"
  tagline + triskelion, used for the default social share image
  (`public/images/misc/og-default.png`, white-on-forest).
- `logo-icon-*.png` &mdash; the house mark only, used to generate the
  favicon/app icons (`src/app/icon.png`, `src/app/apple-icon.png` &mdash;
  white icon on a forest-green background).
- `logo-triskelion-*.png` &mdash; the Manx triskelion symbol, used as a small
  accent next to the footer copyright line.
- `logo-wordmark-*.png`, `logo-monogram-*.png`, `logo-stacked-*.png` &mdash;
  additional lockups (wordmark only, "MQS" monogram, stacked wordmark) not
  currently used in a template but available for future pages, print
  materials, or social profile images.

To regenerate the favicon/app icons or the OG image after updating a logo
file, re-run the equivalent Pillow (PIL) script used to create them (resize
`logo-icon-white.png` onto a forest `#3f4a3a` square for the icons; composite
`logo-full-white.png` onto a 1200x630 charcoal/forest gradient for the OG
image), or recreate them in an image editor at the same paths.

## Replacing Placeholder Images

Real photography has not been supplied yet, so `public/images/` is populated
with clearly-labelled placeholder SVGs (each one shows its own filename/label
and a "PLACEHOLDER IMAGE" watermark) generated by
`scripts/generate-placeholders.mjs`.

To swap in real photography, replace the file at the same path with a real
`.jpg`/`.png`/`.webp` image (same aspect ratio recommended), for example:

```
public/images/projects/cedar-summerhouse/cover.svg -> cover.jpg
```

Then update the corresponding path string in `src/lib/data/*.ts` (e.g.
`coverImage: "/images/projects/cedar-summerhouse/cover.jpg"`).

To regenerate the full placeholder set (e.g. after adding new
services/projects), run:

```bash
node scripts/generate-placeholders.mjs
```

## Configuring the Contact / Quote Form

The contact form (`/contact`) posts to `POST /api/contact`
(`src/app/api/contact/route.ts`), which validates submissions with Zod and
then delivers them via whichever integration is configured through
environment variables — no credentials are hardcoded in the app.

Copy `.env.example` to `.env.local` and set **one** of:

- `RESEND_API_KEY` + `CONTACT_FROM_EMAIL` (and optionally `CONTACT_TO_EMAIL`)
  to send enquiries (including any attached reference images) via the
  [Resend](https://resend.com) API.
- `CONTACT_FORM_WEBHOOK_URL` to POST the enquiry as JSON to a generic
  endpoint (Zapier, Make, a Formspree-compatible service, etc.).

If neither is configured, submissions are logged to the server console so
the form remains fully functional in local development.

`NEXT_PUBLIC_SITE_URL` should also be set to the production domain — it's
used for canonical URLs, Open Graph tags and the sitemap.

## Deployment

The app is a standard Next.js application and deploys cleanly to
**Vercel** (recommended): connect the repository and set the environment
variables from `.env.example` in the project settings.

If a backend/API or image storage integration (e.g. S3) is added later for
handling uploaded reference images, keep it as a clearly separated service
with least-privilege IAM credentials rather than embedding cloud credentials
directly in this Next.js app.
